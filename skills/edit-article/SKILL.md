# 文章编辑（edit-article）

重组文章章节、提升清晰度、精简文字的编辑工作流。

## 触发时机

当用户表示要编辑、修订、重写或改进一篇文章草稿时触发，典型场景包括：

- "帮我编辑/修改/改进这篇文章"
- "把这几段写得更清楚、更连贯"
- "精简一下文字"、"删掉冗余"
- "重新组织这篇文章的结构/章节顺序"

## 工作流

### 第 1 步：划分章节并确认结构

1. 根据文章的标题/小标题，把文章划分成若干章节。
2. 想清楚每个章节要表达的主要观点。
3. 把信息视为一张有向无环图（directed acyclic graph）：一条信息可能依赖另一条信息。确保章节的排列顺序以及章节内部的内容遵循这些依赖关系——被依赖的信息要先讲，依赖它的信息放在后面。
4. 与用户确认章节划分结果，征得同意后再进入下一步。

### 第 2 步：逐章节改写

对每个章节执行以下操作：

1. **重写该章节**，以提升其清晰度、连贯性和流畅度。
2. **段落长度**：每段最多 240 个字符。

## 检查清单

- [ ] 章节顺序符合信息依赖关系（先讲被依赖的内容，再讲依赖它的内容）
- [ ] 章节划分已与用户确认
- [ ] 每段不超过 240 个字符
- [ ] 改写提升了清晰度、连贯性和流畅度
